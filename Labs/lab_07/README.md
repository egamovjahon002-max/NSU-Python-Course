# NSU Python — Lab 07

## Strings and Regular Expressions

Corresponds to Lecture 07 / Section 7. Complete Tasks **1–12** in `tasks.py`. Tasks **13–14** are optional bonus tasks. Use string methods for fixed text operations and `re` for patterns. A regex match checks format, not real-world validity.

Run `python tasks.py` on Windows (or `py tasks.py`) and `python3 tasks.py` on macOS/Linux. No external packages or files are needed. Add your solution below each task and test extra inputs. Submit your completed `tasks.py` through your usual course repository.

Files: `tasks.py`, `README.md`, and `examples/strings_regex.py`. Instructor solutions are distributed separately.
