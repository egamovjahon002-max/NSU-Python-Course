# NSU Python — Lab 08

## Working with Text Files

Corresponds to Lecture 08 / Section 8. Complete Tasks **1–12** in `tasks.py`. Tasks **13–14** are optional bonus tasks.

Keep the supplied `data/` folder next to `tasks.py`. Write generated files to `output/`, which already exists. `tasks.py` defines `DATA` and `OUTPUT` paths relative to the lab folder, so use `DATA / "note.txt"` in `open()`. Open text files with `encoding="utf-8"` and `with`. Read input fixtures without editing them. Tasks using `w` replace an earlier output; Tasks 6 and 7 deliberately behave differently across repeated runs.

Run `python tasks.py` on Windows (or `py tasks.py`) and `python3 tasks.py` on macOS/Linux. Complete the tasks in order. Submit your completed `tasks.py` and any generated output requested by your instructor through your usual course repository.

Files: `tasks.py`, `README.md`, `examples/file_basics.py`, `data/`, `output/`. Instructor solutions are distributed separately.
